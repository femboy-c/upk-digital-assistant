# Чек-лист проверки и сдачи

## Подготовка

- [ ] Установлены зависимости: `.venv/bin/pip install -r requirements.txt`
- [ ] Для тестов установлены: `.venv/bin/pip install -r requirements-dev.txt`
- [ ] Запущен сервер: `.venv/bin/uvicorn app.main:app --reload --port 8443 --ssl-keyfile data/certs/upk.key --ssl-certfile data/certs/upk-chain.crt`
- [ ] Открывается https://127.0.0.1:8443
- [ ] Проходят тесты: `.venv/bin/pytest -q` → 60 passed

## Компьютер

- [ ] Открывается форма заявителя.
- [ ] Работает выбор этажа (1, 2, 3) или территории (передний/задний двор).
- [ ] В списке есть столовая, спортзал, актовый зал, раздевалки, медпункт и санузлы.
- [ ] Корпус в форме не выбирается.
- [ ] Кнопка «Проверить текст» у ИИ-помощника отвечает.
- [ ] Заявка отправляется и получает номер `ДГУ-ГГГГ-NNNNNN`.
- [ ] Сохраняется ссылка отслеживания `/t/КОД`.
- [ ] Вход сотрудника работает (`staff` / `staff123`).
- [ ] Открываются список, поиск, фильтры и карточка заявки.
- [ ] Пагинация списка работает, фильтры сохраняются при переходе по страницам.
- [ ] Невалидный фильтр не даёт ошибку 500, а показывает предупреждение.
- [ ] Назначается исполнитель и меняется статус.
- [ ] Исполнителя можно снять пунктом «— не назначен —».
- [ ] После статуса «Решена» появляется подтверждение.
- [ ] По ссылке отслеживания виден новый статус и публичный комментарий.
- [ ] Внутренняя заметка не видна заявителю.
- [ ] Статистика открывается и показывает реальные числа.
- [ ] Администратор может создать и изменить помещение/QR.
- [ ] Скачивается PNG QR-кода.

## Смартфон

- [ ] В `.env` задан `PUBLIC_BASE_URL=https://IP-компьютера:8443`.
- [ ] Сервер запущен с `--host 0.0.0.0`.
- [ ] Телефон и компьютер в одной сети.
- [ ] QR считывается камерой и открывает форму.
- [ ] Этаж и помещение подставлены правильно.
- [ ] В шапке и подвале указан «Колледж ДГУ».
- [ ] Форма удобно заполняется на узком экране.
- [ ] Таблица заявок превращается в карточки с подписями.
- [ ] Кнопки и поля не выходят за пределы экрана.
- [ ] Панель сотрудника и статистика читаемы на смартфоне.

## ИИ-помощник

- [ ] «Как подключить ноутбук к проектору?» → типовой вопрос + источник.
- [ ] «В кабинете 214 не работает проектор» → неисправность + категория + черновик.
- [ ] «Не работает» → уточняющий вопрос.
- [ ] «В розетке искрит и пахнет гарью» → опасная ситуация.
- [ ] «Как приготовить борщ?» → честный ответ об отсутствии данных.
- [ ] Ответ помощника не отправляет заявку автоматически.
- [ ] В интерфейсе указано, что ИИ демонстрационный.

## Безопасность

- [ ] Без входа `/staff` перенаправляет на `/login`.
- [ ] Сотрудник не может менять привязку QR.
- [ ] Формы без CSRF-токена отклоняются.
- [ ] После 5 неудачных входов появляется блокировка.
- [ ] Вложение недоступно по прямой ссылке из `static/`.
- [ ] Чужое вложение по ссылке отслеживания недоступно.
- [ ] Неверный токен отслеживания не раскрывает данные.
- [ ] Ошибка сервера показывает страницу ошибки, а не успех.
- [ ] Меню аккаунта в шапке открывается и показывает имя, роль и разделы панели.
- [ ] Переключатель темы переключает светлое и тёмное оформление.
- [ ] После перезагрузки выбранная тема сохраняется.
- [ ] Страница «Настройки аккаунта» показывает профиль и форму смены пароля.
- [ ] Смена собственного пароля работает: `/staff/password`.
- [ ] Ответы содержат защитные заголовки `X-Frame-Options`, `nosniff` и CSP.
- [ ] `/staff`, `/track` и `/t/...` отдают `X-Robots-Tag: noindex`.
- [ ] `/robots.txt` запрещает индексацию закрытых разделов.
- [ ] Неизвестный адрес показывает свою HTML-страницу 404.
- [ ] После 5 заявок за 10 минут появляется сообщение об ограничении частоты.
- [ ] Скрытое honeypot-поле не видно пользователю.

## Перед публичным запуском

- [ ] Настроен HTTPS.
- [ ] Заданы `PUBLIC_BASE_URL=https://...` и `SESSION_HTTPS_ONLY=1`.
- [ ] Заменён `SECRET_KEY`.
- [ ] Сменены демо-пароли `staff123` и `admin123` или демо-пользователи удалены.
- [ ] При работе за Caddy/nginx задан `TRUST_PROXY=1`.
- [ ] Проверено, что при `APP_ENV=production` демо-пользователи не создаются.
- [ ] Настроено резервное копирование `data/upk.db` и `data/uploads/`.
- [ ] Проверено свободное место под вложения.
- [ ] Для нескольких процессов решён вопрос общего счётчика попыток входа.
- [ ] Убраны лишние демо-данные.
